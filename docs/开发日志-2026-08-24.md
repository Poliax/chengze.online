# 2026-08-24 开发日志

> 版本基线：v1.4.1
> 当前版本：v1.7.0

## 一、官网课程中心

1. 课程中心重构为页内下钻：一级课程包 → 二级课程包 → 课程详情，不再跳转独立页面。
2. 课程详情采用三个 Tab：课程目录、课程简介、教师简介。
3. 课程目录即课表，支持按科目切换，显示上课时间、时长和“开始学习”入口。
4. 教师简介展示全部教师，头像 + 姓名 + 简介，一位教师一行。
5. 课程简介包含课程内容、课程信息和退费规则。
6. 已直播结束的课次显示实际时长，未直播按排课时长显示，回放删除后不再显示可看状态。
7. 右侧购买卡片只保留价格和“立即购买”。
8. 课程中心顶部增加后台可配置的广告位。

## 二、账号与登录

1. 登录/注册弹窗新增“以游客身份进入”。
2. 登录新增“记住密码”，下次自动填充。
3. 右上角不再显示用户标识，身份信息保留在左侧侧边栏。

## 三、网址规范化

1. 官网入口统一为 `/`，`/live/student` 自动跳转。
2. 课程包详情新地址 `/packages/:id`，旧地址 `/packages/s/:id` 自动跳转。
3. 旧版独立课程页 `/live/student/courses/:id` 自动跳回课程中心。
4. 后台旧地址 `/admin/staff`、`/admin/courses`、`/admin/students`、`/admin/orders`、`/admin/logistics`、`/admin/live-manage/replay` 自动跳转到对应 `-manage` 新地址。

## 四、性能与稳定性

1. 全站启用 gzip 压缩。
2. 源站启用 443 HTTPS，证书自动续期。
3. Cloudflare 切换为 DNS-only 直连。
4. 修复 Mac 浏览器因 Clash 系统代理导致的无法访问问题。
5. 页面切换 Tab、切换课程层级时不再左右/上下跳动。
