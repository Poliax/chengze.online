# 承泽教育

当前版本：**v1.9.0**。版本历史见 [CHANGELOG.md](CHANGELOG.md)。

线上运行版本的源码快照，包含官网、学习中心、教师后台和课堂功能。生产密钥、数据库记录、登录会话、上传和课件不在仓库中。

## 本地开发

使用 Node.js 20 或更新版本：

```sh
npm ci --ignore-scripts
npm run dev:local
```

访问 http://127.0.0.1:3001 。开发脚本在 `.local-runtime-v2/` 中运行独立副本，生成仅供本地使用的会话密钥，并根据 `db/development-schema.sql` 初始化空数据库。不会读取项目原有数据库或生产凭据，也不会创建生产账号；云短信、直播和支付需要各自的测试配置后才能使用。

线上源码的历史演示种子不适用于全新数据库，所以开发脚本先创建空结构，再启动原有代码。此开发准备没有部署到生产。同步快照清单见 `scripts/online-source-manifest.json`；package.json 的本地命令、锁文件的官方源地址和开发脚本是在快照基础上增加的开发支持。

## 当前限制

真实短信和正式微信登录尚待接入；直播、录制和跨房间权限仍需真实验收。不能将本仓库快照视为全部安全问题已解决。请先在测试环境验证，再按单项发布流程部署。

## 检查

```sh
node --test tests/static-files.test.js
```

生产入口为 `npm start`，需要服务器端 `live-config.json`、现有数据库及独立维护的业务资源，不使用开发目录。
